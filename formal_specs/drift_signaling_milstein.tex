% DRIFT formal specification -- the Milstein integrator's algebra.
%
% The source of truth is DRIFT's code:
%   drift/signaling.py :: langevin_step / create_langevin_integrator
%       b             = noise_scale * sqrt(clamped_state * (1 - clamped_state))
%       milstein_corr = 0.25 * noise_scale^2 * (1 - 2 * clamped_state)
%                        * (dw^2 - dt)
%       new_state     = state + drift*dt + b*dw + milstein_corr
%   drift/topology.py :: pi3k_akt_mtor_drift
%       effective_pi3k = pi3k * (1 - inh_pi3k)
%       effective_akt  = akt * (1 - inh_akt)
%
% The machine-checkable block below is GENERATED by
%   python3 scripts/export_drift_to_qed.py --spec-sync
% and is verified by
%   python3 scripts/verify_drift_lemmas.py <lemmas> --strict
% which drives QED.
%
% ---------------------------------------------------------------------------
% THEOREM 1 (the state-dependent variance).  The diffusion coefficient the
% implementation uses has the variance
%     noise_scale^2 * state * (1 - state) = noise_scale^2 * (state - state^2),
% which is the polynomial form of the same quantity.
%
% THEOREM 2 (the Milstein correction, expanded).  The correction term is
%     0.25 * noise_scale^2 * (1 - 2*state) * (dw^2 - dt)
%       = 0.25 * noise_scale^2 * (dw^2 - dt)
%         - 0.5 * noise_scale^2 * state * (dw^2 - dt),
% i.e. the implemented term and the expanded term are the same expression.
% The block states it multiplied by FOUR, for the same reason the bridge's
% identities are scaled: the statement language has no decimal literal,
% and a statement carrying one fails closed instead of being proved.
%
% THEOREM 3 (antisymmetry of the correction).  The correction changes sign
% when the increment's variance is swapped for its complement.
%
% THEOREM 4 (the interval invariant -- A CODE-LEVEL property, not a Lean
% theorem).  "A state in [0, 1] stays in [0, 1]" is enforced by an EXPLICIT
% PROJECTION in the implementation (the step clips the state), not by a dt
% bound, and the statement language cannot carry the premise
% ``0 <= state <= 1`` that the invariant needs.  It is therefore pinned by
% a unit test (drift-unit-gate mission), and it is recorded here so that the
% gap is written down rather than implied: the machine-checked part of this
% file is the ALGEBRA of the step, and the interval property is a property
% of the code.
%
% THEOREM 5 (the inhibition is multiplicative).  The signaling drift's
% effective species levels are the species level scaled by one minus the
% inhibition, which is the expansion the implementation uses.
%% QED-BEGIN
%% QED noise_scale * noise_scale * state * (1 - state) = noise_scale * noise_scale * (state - state * state)
%% QED noise_scale * noise_scale * (1 - 2 * state) * (dw * dw - dt) = noise_scale * noise_scale * (dw * dw - dt) - 2 * noise_scale * noise_scale * state * (dw * dw - dt)
%% QED noise_scale * noise_scale * (1 - 2 * state) * (dw * dw - dt) + noise_scale * noise_scale * (1 - 2 * state) * (dt - dw * dw) = 0
%% QED pi3k * (1 - inh_pi3k) = pi3k - pi3k * inh_pi3k
%% QED akt * (1 - inh_akt) = akt - akt * inh_akt
%% QED k_akt_act * fb_akt * (1 - akt) * (pi3k * (1 - inh_pi3k)) = k_akt_act * fb_akt * (1 - akt) * (pi3k - pi3k * inh_pi3k)
%% QED-END
